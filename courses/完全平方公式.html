完全平方公式

初中数学 · 整式运算 · 约 15 分钟

完全平方公式是整式乘法中最重要的公式之一，描述了两数之和（或差）的平方展开后的规律。

📌 核心公式

(a + b)²  =  a² + 2ab + b²
完全平方和公式
(a − b)²  =  a² − 2ab + b²
完全平方差公式
💡
两个公式的结构完全相同，唯一的区别是中间项 2ab 的符号： 和的平方取 +，差的平方取 −。

✏️ 代数推导

用多项式乘法来严格证明公式：

1
把平方展开为两个括号相乘
(a + b)² = (a + b)(a + b)
2
用分配律展开（每一项都要乘）
= a·a + a·b + b·a + b·b
3
合并同类项（a·b 和 b·a 相同）
= a² + 2ab + b²
⚠️
常见错误：(a + b)² ≠ a² + b²
漏掉中间的 2ab 项是最典型的错误，几何图上的两个绿色矩形就是这一项！

🧠 记忆口诀

首平方，尾平方
2 倍首尾放中间
符号与括号里相同
适用于 (a ± b)² 的展开

📝 例题讲解

例 1  展开 (x + 3)²

📖
令 a = x，b = 3，代入公式：
(x + 3)² = x² + 2 × x × 3 + 3² = x² + 6x + 9

例 2  展开 (2x − 5)²

📖
令 a = 2x，b = 5，用差的平方公式：
(2x − 5)² = (2x)² − 2 × 2x × 5 + 5² = 4x² − 20x + 25

例 3  计算 99²（活用公式）

✨
把 99 写成 (100 − 1)，然后用差的平方：
99² = (100 − 1)² = 100² − 2×100×1 + 1² = 10000 − 200 + 1 = 9801
